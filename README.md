# Maldives Datathon 2026: Transport project ideas

Research-backed options for the [Maldives Datathon 2026](https://www.datathon.stats.gov.mv/), focused on Greater Malé and inter-island mobility.

**[Browse the ranked comparison and all 25 ideas](outputs/ideas/README.md).** Each idea has its own Markdown brief with sources, data requirements, a datathon demo plan, and longer-term rollout considerations.

Research checked 23 September 2026. These are project concepts, not built prototypes. Claims about a comparable Maldivian product are marked **not verified** where the available sources could not establish its status.
