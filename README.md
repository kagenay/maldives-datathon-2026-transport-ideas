# Maldives Datathon 2026: Transport project ideas

Research-backed options for the [Maldives Datathon 2026](https://www.datathon.stats.gov.mv/), focused on Greater Malé and inter-island mobility.

**[Browse the ranked comparison and all 25 ideas](outputs/ideas/README.md).** Each idea has its own Markdown brief with sources, data requirements, a datathon demo plan, and longer-term rollout considerations.

Research reviewed 24 September 2026. The ranking now emphasizes Greater Malé road, bus, walking and bridge-transition decisions; ferry ideas mainly address outlying atolls and national travel. A ferry–flight–bus connection idea is included with explicit data-rights limits. These are project concepts, not built prototypes. Claims about a comparable Maldivian product are marked **not verified** where sources could not establish its status.
